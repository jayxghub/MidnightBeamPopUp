# MidnightBeam Quick Popup

A prototype addon for [MidnightBeam](https://github.com/MadeinTaly/midnightbeam) adding a remote-friendly floating overlay with editable, named presets, intended for Fire TV Stick with Stickman.

**Status:** untested prototype. Do not uninstall the working MidnightBeam app until a test APK has successfully built.

This repository will hold the build workflow and addon source. The original MidnightBeam project is upstream and is licensed under MIT.
